# tum-ai

平成のWindows風デザインを採用した、ブラウザ完結型のAI育成・チャットテストアプリケーションです。外部のAPIキーやサーバー設定は不要で、ブラウザ上ですぐにAIとのチャットや知識の追加が行えます。

---

## 使い方

特別なインストールやビルド環境は必要ありません。以下のURLにアクセスするだけで、すぐにご利用いただけます。

* **Webサイト**: [https://teumadesu.github.io/tum-ai/](https://teumadesu.github.io/tum-ai/)

1. 上記のURLにアクセスします。
2. すぐにチャットやAIの育成を始めることができます。

*(データはブラウザの LocalStorage に自動保存されます)*

---

## 主な機能

* **平成風UI**: 懐かしいWindowsのウィンドウやボタンを再現したカスタムデザイン（Tailwind CSS併用）。
* **AIのカスタマイズ**: AIの名前、アイコン、性格、デフォルトの返答などを自由に設定可能。
* **知識の学習機能**: 質問と答えのペアを追加して、AIの知識データベースをその場で拡張。
* **未知の質問への対応**: AIが答えられない質問を受け取った際、その場で直接正しい答えを教えて学習させることが可能。
* **データ管理（JSON）**: 育てたAIの知識データや設定をJSONファイルとしてエクスポート・インポート可能。
